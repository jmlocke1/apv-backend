# apv-backend
Api de la clínica veterinaria en el proyecto FullStack JS

# Despliegue de la aplicación
Cuando se despliegue en el servidor hay que realizar los siguientes pasos adicionales
- Crear el fichero config/config.js. Copiar el contenido de configDemo.js en config.js y sustituir los valores por los que correspondan al servidor donde se despliegue
- En desarrollo teclear en consola npm run dev para levantar el servidor de desarrollo
